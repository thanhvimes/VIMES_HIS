# Module: Reception (Tiếp đón)

Hệ thống hỗ trợ nhân viên y tế tại quầy hoặc ki-ốt tiếp đón bệnh nhân.

## Chức năng chính
- Tìm kiếm bệnh nhân từ dữ liệu gốc HIS (hms_patient).
- Kết nối thông tin từ đăng ký online vào hệ thống tại quầy.
- Quản lý đồng bộ thông tin hành chính (CCCD, SĐT, Địa chỉ).

## Thành phần backend liên quan
- Controller: `reception.controller.js`
- Routes: `reception.routes.js`
