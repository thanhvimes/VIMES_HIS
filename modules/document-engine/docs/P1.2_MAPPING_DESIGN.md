# P1.2 HIS/EMR to Data Contract Mapping

## Muc tieu

Quan ly mapping versioned giua du lieu nghiep vu HIS/EMR va contract cua template, khong hard-code mapping trong tung mau.

## Cau truc mapping

```json
{
  "code": "RECEPTION_PATIENT_V1",
  "moduleCode": "reception",
  "contractCode": "PATIENT_PROFILE",
  "version": 1,
  "mappings": [
    { "source": "patient.fullName", "target": "patient.name", "transform": "trim", "nullable": false },
    { "source": "patient.dateOfBirth", "target": "patient.dob", "transform": "date:dd/MM/yyyy", "nullable": true }
  ],
  "status": "DRAFT"
}
```

## Quy tac an toan

- Chi cho phep source/target path khong vuot pham vi contract.
- Transform phai nam trong allowlist: `trim`, `uppercase`, `lowercase`, `date:*`, `number`, `boolean`, `enum:*`, `default:*`.
- Khong cho phep eval, JavaScript tu do hoac truy cap truc tiep database tu mapping.
- Mapping da publish khong duoc sua; tao version moi.
- Preview phai dung du lieu gia hoac da mask thong tin nhay cam.

## Lo trinh API

1. `GET /template-studio/mappings?moduleCode=&contractCode=`
2. `POST /template-studio/mappings` tao DRAFT.
3. `POST /template-studio/mappings/:id/preview` preview du lieu mask.
4. `POST /template-studio/mappings/:id/versions` tao version moi.
5. `POST /template-studio/mappings/:id/publish` publish sau khi validate contract.

## Tieu chi nghiem thu

- Mapping object, array, nullable va default.
- Loi path/transform tra ma loi on dinh.
- Preview khong lam lo PII.
- Rollback ve version truoc khong can restart.
